Game formulas

How the game turns its data into the numbers you see, read from the game's own code (client 1.1.146). Time is in frames, 30 per second. The game calculates in 32-bit floats; "cut" means the fraction is dropped (toward zero).

Deploy cost

Cost = A + cut( A × (B − 1) ) + C          (never below 0, no upper limit)

A = U + K
U = the unit's own cost (3, 4 or 5)
K = the class tier's cost (Warrior 11, Guardian 19, Sniper 8 …)
B = (1 + % up − % down), the same four groups as Stats in battle
C = flat increases − flat cuts
  • U is only the unit's share; most of the cost comes from the class.
  • C adds up every flat change on the unit: her own sub skill ("Deploy cost −1" … −10, or a "cost sacrifice" +2 … +10), race trait and awakening nodes, and the "in the party" sub skills of other units (Paradigm Cost −3 for every ally; Summer Partnership −1 for allies of its holder's element, itself included; not for Neutral).
  • B: only one effect changes the cost by %: Late Summer's Rise and Fall, +100 %.
  • The % works on A only (before the flat changes), and its change is cut, not the result: a % cut rounds against you.
  • All of this is fixed before the battle. In battle, map or quest effects can still add or take cost for units that match their condition (no unit or sub skill does this now); the cost again never goes below 0.
  • The game also stores a "cost-down level" per unit, but the cost code doesn't use it.

Examples: Platina 5 + Guardian 19 = 24. With 4th Anniversary Favor (−4) and a Paradigm Cost unit in the party (−3): 24 − 7 = 17. With Counter Party (−10): 14. With Late Summer's Rise and Fall: 24 + 24 = 48.

Base stats (HP, ATK, DEF, MDEF)

Stat = cut( (Min + (Max − Min) × L) × P / 100 )

L   = (level − 1) / max level        (kept between 0 and 1)
Min = the class tier's lowest value for this stat
Max = the class tier's highest value for this stat
P   = the unit's own % for this stat (about 110–130)
  • L divides by the max level, not max level − 1, so even at max level it is a little under 1 (149 / 150).
  • Max level = 30 (the same for every rarity) + 120 (the bonus of the highest rank, rank 5) = 150.
  • Equipment, the personal weapon's level bonuses and abilities are added afterwards.
  • There is no separate magic attack: magic classes use ATK.

Other stats from the class

Attack speed = S + 100 (%)
Crit chance  = 0 %   + awakening,  never above 50 %
Crit damage  = 150 % + awakening,  never above 300 %

S = the class tier's attack speed value
  • Range, Block, Targets, attack interval, move speed: the class tier's values as they are.
  • Crit damage is shown in the game as +50 %: the part on top of normal damage.
  • Flying units: Block 0, whatever the class says (seen in game).
  • Element: ×1.2 with advantage, ×0.8 with disadvantage (see Damage).
  • Awakened (the gold text in race traits) = all 5 awakening nodes unlocked: every node costs 1 point and the points must reach 5.
  • The game's stat panel (潜在覚醒 view) and the wiki's Stats tab: Lv. Max = class 5, max level, with every awakening node that changes a stat (HP, ATK, DEF, MDEF, range, attack speed, deploy cost, crit); Lv. 1 = class 1, level 1, no awakening. Neither includes equipment, sub skills or the personal weapon.

Skill levels

R = (level − 1) / (N − 1)          (N = 1: R = 1, the last-level values)

N = how many levels the skill has = its upgrade recipe's highest level + 1   (no recipe: 1)
R = the level rate: 0 at level 1, 1 at the last level
  • N comes from the skill's upgrade recipe, not from the skill's own "max level" number: every unit skill has 5 levels, including the 100 skills (mostly second skills) whose own number says 1.
  • R is used by the next two formulas.

Example: a 5-level skill at level 3: R = 2 / 4 = 0.5.

Cooldown, duration and cost at a level

Value = cut( R × Last + (1 − R) × First )        (frames; ÷ 30 for seconds)

R     = the level rate (Skill levels)
First = the value at level 1
Last  = the value at the last level
  • The same for the cooldown, the duration and the skill's cost.
  • An OC skill's cooldown uses its parent skill's R.

Example: Platina's Dullahan Form, cooldown 1470 → 1350 frames: 49, 48, 47, 46, 45 s.

Effect values at a level

V     = (1 − R) × First + R × Last
Value = V rounded up if it is within 0.1 of the next whole number, otherwise V cut

R     = the level rate (Skill levels)
First = the effect's value at level 1
Last  = the effect's value at the last level   (0 = no change with level: Value = First)
  • A few skills have extra levels past the last one, where the value goes on from Last toward a third value; no unit skill uses this now.

Example: Soul Blade, ATK +20 % → +50 %. Level 2: V = 0.75 × 20 + 0.25 × 50 = 27.5, not within 0.1 of 28, so 27. All five levels: ×1.2, ×1.27, ×1.35, ×1.42, ×1.5.

How effect numbers read in the texts

"… up" effects       ×(1 + V / 100)        V 60  → ATK ×1.6
"… down" effects     ×(1 − V / 100)        V 30  → ×0.7
"% of a stat"        V / 100 × the stat    V 400 → heals ATK ×4
other effects        V / 100,  or V as it is

V = the effect's value at the skill's level (Effect values at a level)
  • "% of a stat" uses the unit's own ATK, HP, DEF or MDEF.
  • Durations and costs in the texts are the skill's own at its level, in seconds.

Stats in battle

Stat = A × B + C          (then kept inside the stat's limits)

A = the stat before battle            (Base stats above)
B = (1 + Normal %) × (1 + Map %) × (1 + Prayer %) × (1 + Extra %)
C = flat buffs − flat debuffs
  • A: the unit's own stat from her class tier and level, plus awakening, equipment and the personal weapon's level bonus.
  • B: every buff and debuff belongs to one of four groups (Normal, Map, Prayer, Extra). Inside a group the % values add up; the groups multiply. Each group's % = its % buffs − its % debuffs.
  • C: fixed amounts ("ATK +100") are added once, after the %.
  • A debuff on a target with resistance is smaller: debuff × (100 − resistance) / 100.
  • Only the highest counts (no adding) for Attack speed % and Move speed %. That is why the game has a separate "attack speed (stacks)" effect for the ones meant to add.
  • A "fixed" effect (for example range fixed) replaces the result.
  • ATK, DEF and MDEF in battle stay between 50 % and 1000 % of A, and debuffs on them are made smaller by the target's "base status" resistance.
  • "In the party" effects are added the same way before the battle, so they are already inside A.
  • The unit's skills and traits are most likely Normal; which effects use Map, Prayer and Extra is not checked yet.

Example: ATK 1000, a skill ATK +20 % and a trait ATK +30 % (both Normal), and ATK +100: 1000 × (1 + 0.5) + 100 = 1600.

Stacking (all effects)

same kind, same group       add          +20 % and +30 %  = +50 %
same kind, other groups     multiply     ×1.2 × 1.3       = ×1.56
flat (+100, −1)             add, after the %
damage up / damage cut      each multiplies on its own
only the highest counts     attack speed %, move speed %, darkness (miss %), poison, scratch damage
"fixed" effects             replace the value
  • The same rules for every source: skills, race traits, awakening nodes, the personal weapon, sub skills, and other units' "in the party" effects. Two different effects of the same kind both count.
  • Sub skills on one unit: the game groups a unit's sub skills by their Japanese name up to the first space (「攻撃力強化 III」 → 「攻撃力強化」). One sub skill per group works: the higher rarity (equal rarity: the first one). So the same sub skill twice counts once, and the tiers of a line (HP Boost I–IV, ATK Boost I–IV …) count only the highest. Any other name is its own group: ATK Boost IV + ATK Boost+Crit Rate both count. Only the name decides, not what the sub skill does.
  • "In the party" effects: each unit's sub skills are grouped as above first, then the party effects of all units add up into one table. Two different units with the same party sub skill both count (two Paradigm Cost holders: deploy cost −6).
  • Debuffs are subtracted inside the same group, then limits apply (see Stats in battle; deploy cost never below 0).
  • The four groups are Normal, Map, Prayer and Extra (Stats in battle).

Damage

Damage = ( the larger of  H − D ,  H × 10 % ) × (1 − cut₁ %) × (1 − cut₂ %) × …

H    = ATK × (1 + up₁ %) × (1 + up₂ %) × … × Crit × E
Crit = crit damage %  (150 % = ×1.5)      only on a critical hit; otherwise ×1
E    = element: ×1.2 advantage, ×0.8 disadvantage, otherwise ×1
D    = target's DEF (physical), MDEF (magic), 0 (true damage)
  • ATK: the attacker's ATK in battle (Stats in battle). A skill's "ATK ×1.8" is an ATK buff, so it is already in here. An effect that "deals X % of ATK" hits with X % of ATK instead.
  • Damage up %: each effect is its own (1 + up %), and they multiply: +20 % and +30 % = 1.2 × 1.3 = +56 %, not +50 %. They count before DEF. A target's own "damage taken up" when hit counts here too.
  • Crit: a hit is critical if a random number 0–99 is below the attacker's crit chance + the target's extra crit chance taken. Crit damage starts at 150 % (+50 %), cap 300 %, plus the target's extra crit damage taken. A crit multiplies H, so it also counts before DEF.
  • E: from the game's settings (120 and 80).
  • D: DEF or MDEF in battle. True damage (Ignore DEF, 防御無視) skips it.
  • 10 % floor: a hit never does less than 10 % of H, however high the DEF.
  • Damage cut %: each effect is its own (1 − cut %), and they also multiply: −30 % and −30 % = 0.7 × 0.7 = −51 %, not −60 %, so cuts can never reach 100 %. They count after DEF and after the floor. "Damage taken +10 %" is a cut of −10 %: ×1.1.
  • Each step drops the fraction. After that: a fixed-damage effect replaces the number, then cover (an ally takes the hit), barrier, and HP.
  • The data keeps damage up and cut as the whole multiplier, not the %: up 120 = +20 %, 80 = −20 %; cut 70 = 30 % cut (70 % gets through), 110 = takes +10 %. A second number, if there, is the chance it works.
  • Barrier absorbs damage until broken. Its amount is a fixed number, a % of max HP, or a % of ATK.

Example: ATK 2000, damage up +20 %, a crit (150 %), element advantage → H = 2000 × 1.2 × 1.5 × 1.2 = 4320. Target DEF 1500 and damage cut 30 %: (4320 − 1500) × 0.7 = 1974. Same hit on DEF 5000: 4320 − 5000 is below 432, so 432 × 0.7 = 302.

Ailments

How an ailment lands depends on its group. R = the target's resistance to that ailment (0–100).

Stun: a gauge (no dice)

G = G + S × (100 − R) / 100        stunned when G reaches 100

G = the target's stun gauge
S = the effect's stun build-up       (100 or more: stunned at once, R is not used)
R = the target's stun resistance     (100: never stunned)
  • The texts' words: low ≈ 8–15, medium ≈ 35, large ≈ 50, very large ≈ 80.
  • Build-up 100 (stuns in one hit, even through high resistance): Donne skill 1 (on activation, enemies in range; her text doesn't say it) and Seren skill 2.
  • The stun's duration is shortened by a second "stun time" resistance, which enemies only get from effects.

Example: build-up 35 on an enemy with resistance 50: 17.5 per hit, so the 6th hit stuns.

Chance: Poison, Burn, Freeze, Petrify, Darkness, Curse, Launch

lands if  a random number 0–99  <  C × (100 − R) / 100

C = the effect's chance (%)
R = the target's resistance to it    (100: immune)
  • "Ailment chance up" effects raise C. The texts' words (rarely, low, medium, high) follow no rule: 20 % is called "rarely", "low" or "medium" on different units, so the wiki shows the numbers.
  • Burn: damage = a % of the attacker's ATK, every 3 s, as true damage; usually 30 s.
  • Poison: one poison with three strengths: 120 Poison (毒), 190 Deadly Poison (猛毒), 280 Super Poison (超毒). The strength is the damage: every 3 s the target takes exactly that much true damage (DEF doesn't help), so 190 ≈ 63 per second. Several poisons don't add up: the strongest counts. Often lasts until cured. Poison does not stop healing; 水毒禍 (Water Poison Curse) is a different status that blocks some healing and deals 7 % of current HP every 2 s.
  • Freeze: usually 6 s. Petrify: usually 6 s, with its own "petrify time" resistance too.
  • Darkness: the target misses 40 % or 60 % of its attacks; only the strongest darkness stays on a target.
  • Curse: always 100 % chance; 13 kinds, each its own effect (for example 1 % of max HP every second).
  • Launch: a chance and a duration.

Example: 30 % chance on an enemy with resistance 50: lands 15 % of the time.

Always land: Time stop, Bind, Web, Tentacle

No dice and no resistance: enemies have no resistance to these at all.

  • Time stop: 0.5–1 s. Bind: 2–3 s. Tentacle: 5 s.
  • Web: slows the target's attacks and movement by a %.
